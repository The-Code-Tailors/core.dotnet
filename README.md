My framework

## Core.Data

The **Core.Data** library constitutes the heart of my framework and includes several utility classes

## Core.DataAccess

The **Core.DataAccess** library constitutes the data access layer of my framework

## Core.FormattingObjects

The **Core.FormattingObjects** library is a wrapper for the **Fonet** library and includes classes that help creating PDF documents

## Core.LearningManagement

The **Core.LearningManagement** library

## Core.Office

The **Core.Office** library includes classes that help creating DOCX and XLSX documents

## Core.Packager

The **Core.Packager** library is a wrapper for the [ICSharpCode.SharpZipLib](https://github.com/icsharpcode/SharpZipLib) library and includes classes that help manipulating ZIP files

## Core.Presentation

The **Core.Presentation** library includes classes that help building the GUI of ASP.NET MVC web applications
